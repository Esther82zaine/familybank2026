Internet Banking System

An overview of a PHP and MySQL project that demonstrates common online banking workflows.

Demo availability

This GitHub Pages site is informational only. It does not run the PHP/MySQL application. Sign-in, accounts, deposits, withdrawals, transfers, and other banking functions are unavailable here.

Do not enter personal information, passwords, or real banking details on this page.

Project overview

The source project includes separate customer, staff, and administrator areas, with a MySQL schema for accounts and transaction records. It is intended for local setup or deployment to a PHP-capable host with a configured database.

Technologies: PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap.
